# 备考助手（CET-4/6 · 考研英语一/二）

面向中国大学生的英语考试备考辅助工具，覆盖 **CET-4、CET-6、考研英一、考研英二**，界面为中文，题目与语料为英文。**开箱即跑，内置题库，无需安装任何依赖。**

---

## 〇、纯阅读模式（沉浸阅读）

进入任意一篇文章后，**只保留文章正文与译文**，隐藏顶栏、侧边栏、题目区与所有干扰元素。

| 操作 | 方式 |
|---|---|
| 进入 | 文章页右上「进入纯阅读」按钮 / 右下浮动按钮 / 按 **F** |
| 退出 | 纯阅读工具条「退出」/ 按 **Esc** / 按 **F** 再次切换 |
| 字号 | 工具条 A− / A+，或按 **−** / **+** |
| 行间距 | 工具条「行距」，或按 **L**（1.5 / 1.75 / 2.0 三档循环） |
| 日间夜间 | 顶栏「夜间」按钮或按 **D** |

- **保持阅读位置**：进入与退出时都会锚定你当前正在看的那一段，切换后该段仍停在屏幕同一高度，不会跳回顶部。
- **偏好记忆**：字号、行距、配色写入 localStorage，下次打开自动恢复。
- 离开文章页会自动退出纯阅读模式，界面完整还原；在输入框里打字时快捷键不会误触发。

## 一、怎么用（三步上手）

**第 1 步：打开**

双击 `index.html`（推荐 Chrome / Edge；听力的朗读功能依赖浏览器语音合成，Safari 可能无声）。不需要装环境、不需要联网、不需要服务器。

如果双击后浏览器地址栏是 `file://` 开头，功能完全一致，只是无法使用"本地文件导入"之外的跨域能力（本项目无此依赖）。

**第 2 步：先做一次设置（只需 30 秒）**

进入 ⚙️ 设置：

1. 点选考试类型（CET-4 / CET-6 / 考研英一 / 考研英二）——**这个决定每日推送和题库筛选**
2. 设置目标考试日期，首页会显示倒计时
3. 设置每日任务量（默认：阅读 1 篇 / 翻译 1 题 / 写作 0 篇 / 精听 3 句 / 复习生词 10 个）

**第 3 步：按首页的每日闭环走一遍**

```
首页看任务 → 每日推送阅读（含参考译文）→ 做错的题自动进错题本
    → 遇到生词加入生词本 → 第二天首页收到复习提醒 → 周日看统计周报
```

各模块玩法速查：

| 想练什么 | 去哪 | 关键操作 |
|---|---|---|
| 阅读 | 📖 阅读 | 选难度 → 进文章 → 计时自动开始 → **点击带 🔍 的句子做长难句拆解** → 选完所有选项后点"提交全部答案" → 查看题干定位与干扰项分析 |
| 翻译 | 🔤 翻译 | CET 是中译英段落、考研是英译中长句 → 写完点"提交评分" → 看得分、未覆盖的关键表达、常见错误 → 对照参考译文逐句改 |
| 写作 | ✍️ 写作 | 先展开"写作框架 + 常用句型" → 写作文 → 提交后看**语法 / 衔接 / 词汇升级**三块反馈 |
| 听力 | 🎧 听力 | 📢 播放考试指令 → ▶ 全文连读（按考场节奏）→ 逐句精听点 ▶ → 先盲听再点"显示原文/译文" → 做听写填空并"检查答案" |
| 复习 | 📚 词汇生词本 | 首页有到期提醒 → 进词汇页 → 点"认识 / 不认识"，认识的词间隔拉长（1→2→4→7→15 天） |

### 📢 听力模块：考试级 AI 配音

听力不再依赖浏览器自带语音，而是播放**预生成的微软 Neural TTS 音频**（与 Azure Neural TTS 同源，接近四六级听力播音风格）。

**按题型匹配声线与语速**

| 题型 | 目标语速 | 声线配置 |
|---|---|---|
| 新闻听力 | 145 wpm | 女声播报 Aria（News 风格） |
| 长对话 | 135 wpm | 女声 + 男声交替（Jenny / Andrew） |
| 短文听力 | 130 wpm | 女声或男声独白（Jenny / Andrew） |
| 讲座听力 | 150 wpm | 男声学术 Eric / 女声学术 Michelle |

**题型覆盖（对照官方听力结构）**

| 考试 | 官方题型 | 现有篇数 | 每篇题量 |
|---|---|---|---|
| CET-4 | 新闻报道（Section A） | 3 篇 | 2 题 |
| CET-4 | 长对话（Section B） | 2 篇 | 4 题 |
| CET-4 | 短文（Section C） | 7 篇 | — |
| CET-6 | 长对话（Section A） | 1 篇 | 4 题 |
| CET-6 | 讲座 / 讲话（Section C） | 3 篇 | 3 题 |
| CET-6 | 短文（Section B） | 1 篇 | — |

合计 18 篇（233 个音频、约 20 分钟）：其中 8 篇带选择题，共 **26 题**；另有 1 篇考研长对话——考研初试不考听力，该篇仅供复试参考，未再新增考研听力。

带选择题的篇目会多出 **📝 听力理解** 板块，与考场形式一致：先听录音作答，提交后给出**正确依据**（对应原文哪一句）以及**每个干扰项分别错在哪**（偷换概念、张冠李戴、时态混淆、以偏概全、无中生有等）。

**六个播放入口**

- **📢 播放考试指令**——朗读该题型对应的官方 Directions 逐字原文（含 `A), B), C) and D)` 括号选项与「Then mark the corresponding letter on Answer Sheet 1」涂卡说明）
- **▶ 全文连读**——按考场节奏逐句播放，句间停顿可选：不停顿 / 3 秒 / **5 秒（推荐）** / 15 秒（真实考试答题时间）
- **🎯 考试模式**——一键还原完整考场流程：指令 → 篇目标识（News report one.）→ 正文只放一遍 → 题组引导（Questions 1 and 2 are based on...）→ **逐题听题+选项并留出作答时间**，听完后屏幕高亮当前题供作答，最后「提交答案」看解析
- **📝 每题「▶ 听题目与选项」**——单题重听：把题干与四个选项一起念出（选项念作 A, … B, … C, … D, …），完全模拟考场"听题作答"
- **逐句 ▶ 播放**——精听单句；👩 / 👨 图标标出该句由女声还是男声朗读
- **🔊 变速 0.5–1.5x**——直接改变音频播放速率并保持音高自然

**语料篇幅按真题校准**：新闻约 100–150 词、四级长对话约 200–250 词、六级长对话约 250–300 词、六级讲座约 350–500 词，与近年真题录音文字稿长度一致（早期短文语料偏短，已统一扩写）。题量分布也对齐官方：四级新闻 2-2-3、长对话每篇 4 题、六级讲座 3-3-4。

**语速是怎么校准的**：各声线自然语速差异很大（实测 159–183 wpm），若统一用同一个 rate，实际快慢会差出一截。脚本先测出每个声线的基准语速 wpm0，再按 `rate = (目标 / wpm0 - 1) × 100` 反推，确保发音速度精确命中目标（如四级短文 130 wpm）。

**离线与自动回退**：音频随项目一起提交（约 14 MB），断网也能听。若音频缺失、或用 `file://` 直接打开导致读取失败，会自动回退到浏览器语音合成，功能不中断。

**重新生成音频**（增删听力题后需要重跑）：

```bash
pip install edge-tts mutagen
python tools/gen_audio.py            # 增量：只补缺失的
python tools/gen_audio.py --force    # 全量重生成
python tools/gen_audio.py --only l5  # 只生成某一篇
```

新增一篇听力时，在 `js/listening_meta.js` 的 `ITEMS` 里加一行，指定 `type`（题型）、`speakers`（说话人序列，F=女声 M=男声）、`dir`（考试指令），再跑一次生成脚本即可。

**数据存在哪**：全部存在浏览器 localStorage（本机），换浏览器或清缓存会丢。建议在设置里定期"导出学习数据（JSON）"备份。

## 二、题库来源说明（重要）

**当前内置题库全部是「按真题风格编写的模拟题（mock）」，不是官方真题原文。**

原因：① 近十年四六级/考研真题有版权，直接内置分发不合适；② 我不愿放入无法逐字核实的"疑似真题"，宁可用风格高度一致的模拟题，保证内容可靠。

内置题库规模：

| 模块 | 数量 | 覆盖 |
|---|---|---|
| 阅读 | **20 篇 / 68 题** | CET-4×6、CET-6×6、英一×4、英二×4；每篇含长难句拆解、逐题考点标签、正确依据与干扰项分析 |
| 翻译 | **13 题**（真题 5 + 模拟 8） | CET-4/CET-6 段落翻译（中→英）、考研英一/英二长句翻译（英→中） |
| 写作 | **9 题**（真题 3 + 模拟 6） | 议论文、图表作文、图画作文、应用文（建议信/通知） |
| 听力 | **6 篇 / 51 句 / 20 个填空** | 短文、讲座、长对话三类 |
| 词汇 | **60 词** | 按考试标注，含词性、释义、例句 |

### 质量校验工具

每次扩充题库后运行，逐条体检：

```bash
node tools/check.js
```

校验项：**结构完整性**（选项须为完整 A/B/C/D）、**答案唯一性**（选项内容互不重复、正确答案在选项内）、**定位有效性**（locate 段落存在）、**长难句可匹配**（否则拆解入口静默失效）、**解析完整性**（须有正确依据与干扰项分析）、**重复度检测**（题干+选项综合相似度，区分同文章/跨文章阈值）、**分布统计**（难度、考试、考点）。

> 该工具已实际抓出并修复过 3 篇长难句匹配失效、1 处干扰项分析混入正确项等隐藏缺陷。

### 已知缺口

早期批次的阅读题（r1–r14，共 40 题）**尚未补写 `basis` 正确依据**，只有干扰项分析；第二批（r15–r20，24 题）已全部配齐。补齐这 40 条是下一批任务。

## 三、怎么把真题库加进去（两种方式）

### 方式 A：导入 JSON（推荐，你自己就能做）

⚙️ 设置 → **题库导入** → 点"下载题库模板"，照着填，然后：

- 拖入 JSON 文件，或
- 直接把 JSON 粘进文本框 → 点"导入粘贴的 JSON"

规则：按 `id`（词汇按 `word`）**同 id 覆盖、新 id 追加**；自定义题库另存一份，清空内置题库不会影响它，反之亦然。

字段格式见模板文件，或看设置页里的"字段说明"表格。

### 方式 B：直接改 data.js

把真题按 `js/data.js` 里现有条目的字段结构追加进去（第二批数据在文件末尾用 `DB.translations.push(...)` 的方式批量追加，加在最后最省事），刷新页面即生效，不用改任何逻辑代码。

### 方式 C：把资料给我

把你的真题（PDF / Word / 图片 / 复制的文本）发我，我按格式转成 JSON 给你导入，或直接写进 `data.js`。**批量真题用这种方式最快。**

### 关于来源可信度的两点提醒

1. **官方不公布真题**：CET 官网（cet.neea.edu.cn）导航栏只有「考试动态 / CET委员会 / 考试大纲 / 考核内容 / 分数解释 / 常见问题」，**没有历年真题栏目**；考研英语官方《考试大纲》附录 3 仅含 2023、2024 两年试题，且需购书。因此所有"真题"均来自第三方公开转载。
2. **警惕 AI 生成的假真题**：检索中发现百度文库某"2024年6月四级真题"页面把「四合院」同时写成阅读选词填空和翻译题——真实考试不可能同卷重复同一话题，该内容为 AI 编造。本项目对每条真题标注来源与验证状态，就是为了把这类内容挡在外面。

### 继续补充真题的三条路

1. **你提供，我转格式**：把真题 PDF / Word / 图片 / 复制文本发我，我按结构转 JSON 导入（**最快、最可靠**，尤其适合补阅读真题）。
2. **我继续分批抓取**：按年份一批一批做，每批都做多源交叉验证后再入库。
3. **自行导入**：⚙️ 设置 → 题库导入，填 `year / month / set / sourceUrls / verified` 字段即可，界面会自动显示真题标记与出处。

## 六、技术说明

- 纯原生 HTML/CSS/JS 单页应用，零依赖、零构建；学习数据与自定义题库均用 `localStorage` 持久化。
- 听力配音使用预生成的微软 Neural TTS 音频（`audio/`，由 `tools/gen_audio.py` 用 edge-tts 生成）；播放时优先加载 MP3，缺失或用 `file://` 打开时自动回退 Web Speech API（`speechSynthesis`）。
- 配音语速按声线逐个校准：先实测各声线在 `rate=+0%` 时的基准语速（159–183 wpm，差异很大），再按 `rate = (目标 / wpm0 - 1) × 100` 反推，使发音速度精确命中四级 130wpm / 六级 150wpm 这类目标。
- 翻译评分 = 关键表达覆盖度 + 长度合理性（漏译/加译会扣分）。
- 写作批改 = 规则匹配（语法正则、衔接词库、词汇升级映射表 + 词汇丰富度），适合日常自测，**不替代人工精改**。
